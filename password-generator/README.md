# 🔐 Secure Password Generator

A robust and secure command-line password generator built with Python. This tool allows users to generate randomized, highly secure passwords by combining letters, numbers, and special symbols based on custom length preferences.

---

## 🚀 Features

- **Customizable Complexity:** Choose the exact number of letters, digits, and special characters.
- **Enhanced Security:** Automatically shuffles the character pool to prevent predictable patterns.
- **Clean CLI Interface:** Simple and intuitive command-line interaction.

---

## 🛠️ Technologies Used

- **Python 3.14** (Standard libraries: `random`, `string`)
