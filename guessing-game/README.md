# 🎯 Number Guessing Game

An interactive command-line number guessing game built with Python. The program generates a random secret number, and the player has to guess it, receiving helpful hints (higher or lower) after each attempt until they succeed.

---

## 🚀 Features

- **Randomized Gameplay:** Generates a unique random number for every new session.
- **Interactive Feedback:** Guides the player with dynamic hints ("Too high!" or "Too low!").
- **Clean CLI Interface:** Simple and engaging command-line user experience.

---

## 🛠️ Technologies Used

- **Python 3.14** (Standard library: `random`)
